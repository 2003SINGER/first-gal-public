> 本文件**只描述叙事与对白**，不含任何代码实现、Dialogic 信号、Godot 节点或交互逻辑。

## Demo 与正式版的关系

> 本条关系贯穿整个 Demo 剧本与 4 个 Timeline，所有"该写死还是该留槽位"的判断都先回到这里。

1. **Demo 是正式版主线后段的"结果态切片"**：它不独立于正式版，也不是正式版的第一章，而是高中三年结束后的毕业日——一个"已经发生了很多事、但玩家尚未亲历"的结果。
2. **正式版会重新回到这里**：正式版未来会进入完整的高中三年过程，并最终重新回到毕业日；届时 Demo 已出现的物件、照片、对白、动作，会获得第二层意义（"原来那时就已经……"）。
3. **Demo 当前的任务不是"加更多意义"，而是区分两类东西**：一类是毕业日当天本来就该真实存在的残留物、习惯、空间状态；另一类必须从正式版三年剧情里长出来的回响。
4. **现在可以写死的**：毕业日当天真实存在的空间状态、普通校园生活里无意义的残留、海象已经形成的习惯、不限定关系性质的熟悉感、不依赖具体主线事件也成立的事实。
5. **现在不能写死的**：为正式版凭空编造的具体共同事件、海象与叶晓关系发展的关键节点、某件物品背后的完整情感故事、S14 六张照片所对应的正式剧情。
6. **凡涉及"回响"的，优先做成槽位**：S05 柜子的部分物品、S14 的照片、若干对白里的潜台词，都按"现在只放得下、以后才读得出"来设计，不提前把完整故事说满。
7. **统一修改标准**：如果一个新增细节必须靠尚未写出的高中事件才能解释，则优先标记为**正式版回填槽位**，不在当前 Demo 中强行定稿。

## 命名与格式约定

- **【旁白】**：海象的内心独白 / 观察者叙述（引擎中无说话人前缀的文本行）。
- **【画面】**：纯视觉提示（照片、空镜、场景切换），不出台词。
- **【海象】【叶晓】【同桌】【同学】【朋友】【朋友A】【朋友B】【老师】**：角色台词。
- 每段含：**地点 / 时间**、**角色**、**正文**、**设计备注**（本场作用 / 关键状态 / 不能破坏的点）。

# S01｜上学路

**地点 / 时间**：家 → 校门外的路；毕业日早晨
**角色**：海象（独处）

**正文**

【旁白】手机震了一下。
【旁白】手已经摸过去。
【旁白】停了一下。
【旁白】才发现是班级群消息。

【旁白】班级群 @所有人
【旁白】升学意向统计没接龙的今天补一下，暂定也行。
【旁白】毕业典礼后回班讲志愿。柜子、桌洞今天清完，东西别留学校。

【旁白】我点开接龙。
【旁白】往下翻。
【旁白】还真没我。

【海象】……到了再填吧。

【旁白】顺手摸一遍。
【海象】资料、相机、手机……
【海象】都在。

【画面】场景切换：校门

【旁白】进校门以后，还是平时那条路。
【旁白】在天天赶路的小道上，今天却走得格外慢。

【画面】场景切换：走廊

**设计备注**
- **本场作用**：开场钩子。用一条班级群消息同时抛出两个核心：①今天是毕业日、要清柜子；②升学志愿还没填。建立海象"手机依赖 / 下意识摸手机"的细微习惯。
- **关键状态**：志愿尚未填（"还真没我"）；海象随身带齐资料、相机、手机。
- **不能破坏**：手机群消息的"动作→停顿→意识"节奏（震了一下 / 手摸过去 / 停了一下 / 才发现是群消息）——不要改成平铺直叙，也不要加"毕业以后没人管手机"之类的总结。

# S02｜教室外走廊

**地点 / 时间**：教学楼走廊；毕业日，典礼前
**角色**：海象（独处，旁观他人）

**正文**

【旁白】快到教室的时候，走廊就开始堵了。
【旁白】前面有人蹲在柜子前收东西。
【旁白】书、袋子、纸箱占了一截过道。
【旁白】我侧身从中间挤过去。
【旁白】教室那头又出来一个抱书的人。
【旁白】我又让了一下。
【旁白】擦过去的时候，旁边不知道谁说了半句。

【旁白】"这个还要不要——"
【旁白】另一边马上回。
【旁白】"不要了，扔。"
【旁白】再后面就听不清了。

【旁白】我往自己柜子那边看了一眼。
【旁白】柜门还关着。
【旁白】包还在肩上。
【旁白】先进去。
【旁白】推门。

**设计备注**
- **本场作用**：用别人清柜子的杂音，铺垫"今天人人都在告别、清理"，反衬海象自己的柜门还关着、包还背着。
- **关键状态**：海象柜门仍关着，包在肩上，尚未落座。
- **不能破坏**：不写海象的心理总结；只用"看一眼柜门 / 包还在肩上"等动作表达。

# S03｜上午教室

**地点 / 时间**：上午教室；同学陆续到齐
**角色**：海象、同桌、叶晓、同学

**正文**

【画面】场景切换：上午教室

【旁白】推门以后，声音一下全挤过来。
【旁白】我们那片位置旁边围了几个人。
【旁白】两张桌子被他们绕成一个小圈。
【旁白】我往里面挤。
【旁白】同桌正靠在我桌边说话，看见我，把手里的本子往旁边挪了一下。

【同桌】来了。
【海象】占我位置开会呢？
【同桌】你来得太晚，位置被征用了。
【海象】我又没迟到。
【同桌】没迟到也不算早。

【旁白】旁边有人让了一下。
【旁白】我从缝里过去。
【旁白】包放下。
【旁白】坐下来。
【旁白】手习惯性摸进校裤口袋，摸到手机。
【旁白】下意识看一眼讲台——今天没人管。
【旁白】我把它搁到桌上。
【旁白】过两秒，又看一眼。

【叶晓】你终于来了。
【海象】差点没挤进来。
【叶晓】毕业典礼还不提前一点到？
【海象】提前到了也还是坐着。
【叶晓】你每次都这么回。
【旁白】我笑了一下。
【叶晓】你柜子清了没？
【海象】还没。
【叶晓】你先别说我。
【海象】我还什么都没说。

【旁白】叶晓看我一眼。
【叶晓】嗯。
【海象】你这个"嗯"是什么意思？
【叶晓】没什么意思。

【旁白】有人叫了叶晓一声。
【旁白】她应了一声，转过去继续聊天。

【旁白】前面有人喊了一声。
【旁白】"去会场了。"

【同桌】走了啊，一起。
【海象】哦。

【旁白】叶晓已经和几个同学到门口了。
【旁白】我把手机揣回去，跟上同桌。

**设计备注**
- **本场作用**：建立海象与同桌、叶晓的相处语气；手机在桌上"下意识看"的小动作；叶晓以一个"像真同学"的轻 presence 出现，不特殊化。
- **关键状态**：海象落座，手机搁桌面；叶晓只是同学之一。
- **不能破坏**：
  - 叶晓前史**不在此解释**（不写"认识多久 / 何时喜欢"）。
  - "你每次都这么回"在本场只出现一次；海象用"我笑了一下"代替回怼，不要扩成反复互怼。
  - 不连续重复"你又… / 我还没… / 你每次…"。

  - 不在这里解释"为什么拍"或"这意味着什么"。

# S16｜叶晓听见

**地点 / 时间**：傍晚空教室
**角色**：海象、叶晓

**正文**

【叶晓】什么收完了？
【海象】没什么。
【叶晓】我听见了。
【旁白】我没接。
【旁白】叶晓看了一眼照片。
【叶晓】你最后就拍这个啊？
【叶晓】空教室有啥好拍的。
【海象】不然拍什么。
【叶晓】人啊。
【海象】那你站过去。
【叶晓】我说的是你。
【海象】我？
【叶晓】嗯。
【旁白】我又看了一眼照片。
【海象】我有什么好拍的。
【叶晓】那就一起。

【旁白】叶晓拿出手机。

**设计备注**
- **本场作用**：叶晓听见"收完了"，把"被拍对象"第一次明确指回海象本人（"我说的是你"），让收尾从拍环境转到拍人；之后自拍，再引出海象"我也给自己单独拍一张"——那一步是海象自己做出的。
- **关键状态**：叶晓拿出手机，准备一起拍。
- **不能破坏**：核心不是暧昧，是"镜头指回海象"；海象整体少接话、不连续嘴贫；不新增主题总结（不升华"青春""离别"）。

# S17｜自拍 / Demo End

**地点 / 时间**：傍晚空教室；收尾
**角色**：海象、叶晓

**正文**

【旁白】叶晓举起手机。
【旁白】我往她旁边挪了一步。
【海象】你往那边一点。
【叶晓】我已经很边上了。
【海象】你头挡住后面了。
【叶晓】自拍你还管后面？

【画面】快门声。照片：毕业自拍。

【画面】静场约 0.8 秒

【旁白】我低头看了一会儿。
【旁白】手指往旁边划了一下。
【旁白】又划回来。

【画面】静场约 0.3 秒

【海象】……
【叶晓】怎么了？
【海象】我也给自己单独拍一张。
【叶晓】现在？
【海象】嗯。
【叶晓】这张还管背景吗？
【海象】不管。

【画面】照片隐去。场景切换：黑场。

【画面】静场约 0.6 秒

【画面】快门声。

【画面】静场约 0.8 秒

（Demo End）

**设计备注**
- **本场作用**：叶晓主动举起手机喊"一起拍"，海象往她旁边挪一步。共同照片出现后，他先看见照片里的自己，才主动提出拍单人照；Demo 在这里收尾。
- **关键状态**：叶晓主动举起手机自拍，海象往她旁边挪一步；自拍后海象看图、划走又划回，再提出单人照。它是“认出自己”的最小动作，不是成长完成。
- **不能破坏**：
  - 自拍前不再用"举起相机 / 犹豫 / 放下"的机械动作表现迟疑；迟疑留给"往旁边挪一步"这个自然动作，不补"其实不想拍 / 想留住这一刻"之类旁白。
  - 不把“看图 → 划走又划回 → 决定”改成哲学独白；不写“原来我总在记录别人”或“我终于学会把自己放进生活”。
  - 不写"青春结束了"之类升华；结尾静场后一声快门，留白。

## 全局原则（落到本剧本的约束）

1. **文本承认客观状态**：S05 塞爆、S06 志愿"暂定"、S13 空教室——都从玩家/角色实际做到的事长出，不造"怀旧度 +3"式作者数值。
2. **命名表达时间/叙事状态**：空教室命名为 `classroom_late_afternoon`（傍晚），不是"empty"。
3. **画面已说的，旁白不重复**：S13 / S14 的空教室与回忆只靠画面 + 快门，不出总结对白。
4. **蒙太奇不等时长**：S14 各碎片停留不同，最终按观看感觉逐段调。
5. **灰盒阶段不新增系统**：无传统分支、无影响结局的选择。若未来加互动，只加"观察方式"（如拍照选教室 / 窗外 / 桌子，仅改一句旁白），不新增剧情或分支。
6. **叶晓前史只以轻痕迹出现**：不写"两人怎么认识"的已知往事点名、不解释认识多久、不写大段回忆；目标是让玩家"明显认识很久但说不清哪天"。任何需要正式版事件才能成立的"前史细节"，一律留作回填槽位。
7. **海象声线**：短句、停顿、动作；纯吐槽每场不超过 1–2 次，其余用"看一眼 / 没接话 / 笑一下 / 继续做自己的事"；"你又… / 我还没… / 你每次…"不连续出现。
