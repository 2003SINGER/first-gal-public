# 《毕业日》Demo 剧本 · 阅读版

> **本文档性质**：面向人工阅读的完整剧本，覆盖 **S01–S17**（从上学路到自拍收尾）。
> 本文件**只描述叙事与对白**，不含任何代码实现、Dialogic 信号、Godot 节点或交互逻辑。
> 实际演出由 4 个 timeline 分段实现：
> `01_return_to_school`（S01–S04）、`02_locker_and_future`（S05–S06）、
> `03_lunch_and_afternoon`（S07–S12）、`04_memory_and_ending`（S13–S17）。
> 柜子 / 收桌子两段为可交互场景，其 UI 文案与判定逻辑不在本剧本内，仅以「（互动）」标注进入点。

---

## 命名与格式约定

- **【旁白】**：海象的内心独白 / 观察者叙述（引擎中无说话人前缀的文本行）。
- **【画面】**：纯视觉提示（照片、空镜、场景切换），不出台词。
- **【海象】【叶晓】【同桌】【同学】【朋友】【朋友A】【朋友B】【老师】**：角色台词。
- 每段含：**地点 / 时间**、**角色**、**正文**、**设计备注**（本场作用 / 关键状态 / 不能破坏的点）。

# S01｜上学路

**地点 / 时间**：家 → 校门外的路；毕业日早晨
**角色**：海象（独处）

**正文**

【旁白】手机震了一下。
【旁白】手已经摸过去。
【旁白】停了一下。
【旁白】才发现是班级群消息。

【旁白】班级群 @所有人
【旁白】升学意向统计没接龙的今天补一下，暂定也行。
【旁白】毕业典礼后回班讲志愿。柜子、桌洞今天清完，东西别留学校。

【旁白】我点开接龙。
【旁白】往下翻。
【旁白】还真没我。

【海象】……到了再填吧。

【旁白】顺手摸一遍。
【海象】资料、相机、手机……
【海象】都在。

【画面】场景切换：校门

【旁白】进校门以后，还是平时那条路。
【旁白】在天天赶路的小道上，今天却走得格外慢。

【画面】场景切换：走廊

**设计备注**
- **本场作用**：开场钩子。用一条班级群消息同时抛出两个核心：①今天是毕业日、要清柜子；②升学志愿还没填。建立海象"手机依赖 / 下意识摸手机"的细微习惯。
- **关键状态**：志愿尚未填（"还真没我"）；海象随身带齐资料、相机、手机。
- **不能破坏**：手机群消息的"动作→停顿→意识"节奏（震了一下 / 手摸过去 / 停了一下 / 才发现是群消息）——不要改成平铺直叙，也不要加"毕业以后没人管手机"之类的总结。

# S02｜教室外走廊

**地点 / 时间**：教学楼走廊；毕业日，典礼前
**角色**：海象（独处，旁观他人）

**正文**

【旁白】快到教室的时候，走廊就开始堵了。
【旁白】前面有人蹲在柜子前收东西。
【旁白】书、袋子、纸箱占了一截过道。
【旁白】我侧身从中间挤过去。
【旁白】教室那头又出来一个抱书的人。
【旁白】我又让了一下。
【旁白】擦过去的时候，旁边不知道谁说了半句。

【旁白】"这个还要不要——"
【旁白】另一边马上回。
【旁白】"不要了，扔。"
【旁白】再后面就听不清了。

【旁白】我往自己柜子那边看了一眼。
【旁白】柜门还关着。
【旁白】包还在肩上。
【旁白】先进去。
【旁白】推门。

**设计备注**
- **本场作用**：用别人清柜子的杂音，铺垫"今天人人都在告别、清理"，反衬海象自己的柜门还关着、包还背着。
- **关键状态**：海象柜门仍关着，包在肩上，尚未落座。
- **不能破坏**：不写海象的心理总结；只用"看一眼柜门 / 包还在肩上"等动作表达。

# S03｜上午教室

**地点 / 时间**：上午教室；同学陆续到齐
**角色**：海象、同桌、叶晓、同学

**正文**

【画面】场景切换：上午教室

【旁白】推门以后，声音一下全挤过来。
【旁白】我们那片位置旁边围了几个人。
【旁白】两张桌子被他们绕成一个小圈。
【旁白】我往里面挤。
【旁白】同桌正靠在我桌边说话，看见我，把手里的本子往旁边挪了一下。

【同桌】来了。
【海象】占我位置开会呢？
【同桌】你来得太晚，位置被征用了。
【海象】我又没迟到。
【同桌】没迟到也不算早。

【旁白】旁边有人让了一下。
【旁白】我从缝里过去。
【旁白】包放下。
【旁白】坐下来。
【旁白】手习惯性摸进校裤口袋，摸到手机。
【旁白】下意识看一眼讲台——今天没人管。
【旁白】我把它搁到桌上。
【旁白】过两秒，又看一眼。
【旁白】我抿了一下。

【同学】你笑什么？
【海象】没笑。
【旁白】旁边有人笑了一声。
【旁白】叶晓接了一句。

【叶晓】你终于来了。
【海象】差点没挤进来。
【叶晓】毕业典礼还不提前一点到？
【海象】提前到了也还是坐着。
【叶晓】你每次都这么回。
【旁白】我笑了一下。
【叶晓】你柜子清了没？
【海象】还没。
【叶晓】你先别说我。
【海象】我还什么都没说。

【旁白】叶晓看我一眼。
【叶晓】嗯。
【海象】你这个"嗯"是什么意思？
【叶晓】没什么意思。

【旁白】她那边有人叫她。
【旁白】叶晓应了一声，转回自己那边。

【旁白】前面有人喊了一声。
【旁白】"去会场了。"

【同桌】走了啊，一起。
【海象】哦。

【旁白】叶晓已经和她那边几个人到门口了。
【旁白】我把手机揣回去，跟上同桌。

**设计备注**
- **本场作用**：建立海象与同桌、叶晓的相处语气；手机在桌上"下意识看"的小动作；叶晓以一个"像真同学"的轻 presence 出现，不特殊化。
- **关键状态**：海象落座，手机搁桌面；叶晓只是同学之一。
- **不能破坏**：
  - 叶晓前史**不在此解释**（不写"认识多久 / 何时喜欢"）。
  - "你每次都这么回"在本场只出现一次；海象用"我笑了一下"代替回怼，不要扩成反复互怼。
  - 不连续重复"你又… / 我还没… / 你每次…"。

# S04｜毕业典礼

**地点 / 时间**：会场；毕业典礼进行中
**角色**：海象、同桌、朋友

**正文**

【画面】场景切换：毕业典礼会场

【旁白】到会场的时候，前面几排已经坐得差不多了。
【旁白】我们从旁边绕进去。
【旁白】坐下。
【旁白】台上还在调话筒。

【同桌】你看，早来也是坐着。
【海象】所以我说。

【旁白】没多久，前面开始讲话。
【旁白】听了一阵。
【旁白】脑子又绕回早上的接龙。
【旁白】学校其实早就看过很多遍。
【旁白】省内的，省外的。
【旁白】稳一点的，冲一点的。
【旁白】专业也翻过一堆。
【旁白】每个都能说出一点理由。
【旁白】每个又都有哪里不太对。
【旁白】真不看表格的时候，好像还都可以。
【旁白】但一放到第一志愿那一格里，就又不是那么回事。

【旁白】前面突然响起掌声。
【旁白】我跟着拍了两下。
【旁白】继续想。
【旁白】如果第一志愿先填一个，后面是不是得稳一点。
【旁白】调剂呢。
【旁白】……

【旁白】前面又响起掌声。
【旁白】班里考得最好的那个领完奖，下台的时候还被拍了两张照。

【旁白】旁边有人小声说。
【朋友】他这分也得纠结专业吧。
【海象】应该吧。
【朋友】这都纠结？
【海象】分高有分高的选法。
【朋友】你说得像你很懂。
【海象】不懂。
【旁白】停一下。
【海象】但感觉什么分都有尴尬的地方。

【旁白】前面又开始讲话。
【旁白】我摸出手机。
【旁白】刚想再翻一眼收藏夹。
【旁白】还没解锁。
【旁白】前排突然开始站人。
【旁白】椅子一片响。
【旁白】我抬头。

【海象】……没了？
【朋友】不然呢？
【海象】我怎么感觉刚坐下。
【朋友】你全程都在发呆。
【海象】那也没这么快吧。
【朋友】要不你留下，再听一场。
【海象】那算了。

【旁白】朋友已经跟着往外走。
【旁白】我把手机揣回去。
【旁白】站起来。
【旁白】回头看了一眼。
【旁白】领导都开始离场了。
【旁白】跟上去。

【画面】场景切换：走廊
（→ 接 S05）

**设计备注**
- **本场作用**：把"志愿纠结"从外部要求变成海象的内部盘算；用会场走神表现他还没想清楚。
- **关键状态**：海象全程发呆，志愿仍悬而未决（"一放到第一志愿那一格里，就又不是那么回事"）。
- **不能破坏**：不替他做决定；不写"我终于决定了"；与朋友的互动只是轻吐槽，不解决志愿问题。

# S05｜柜子整理

**地点 / 时间**：教室外走廊 / 柜子前；典礼后
**角色**：海象、叶晓

**正文**

【画面】场景切换：走廊

【旁白】从会场回来。
【旁白】我先把包放回座位。
【旁白】再出去。
【旁白】自己的柜门还关着。
【旁白】拉开。
【旁白】最上面几张卷子直接滑出来。
【旁白】赶紧用膝盖顶住。
【旁白】还是掉了一本。

【海象】……

【旁白】又掉一张。

【海象】行。

【旁白】蹲下来。

（互动）此处进入「柜子整理」互动，物品检视与取舍在交互界面完成。

**【分支 · 柜子塞爆时】（locker_overpacked 为真）**

【旁白】我把东西往包里压了一下。
【旁白】拉拉链。
【旁白】卡住。
【旁白】再压。
【旁白】还是不动。

【海象】……
【旁白】又拉一次。
【海象】物理上好像不太允许我怀旧。
【叶晓】你到底装了多少？
【海象】没多少。
【叶晓】你包都变方的了。
【海象】别看。

（互动）腾位后继续整理。

【旁白】这次拉链合上了。

**【分支 · 正常时】**

【旁白】拉链正常合上。
【旁白】我拍了拍包。
【叶晓】今天这么舍得？
【海象】嗯。
【叶晓】稀奇。
【海象】你管我。

**设计备注**
- **本场作用**：第一个可交互场景。用柜子里掉出的杂物表现"这是真柜子，不是纪念品展柜"；塞爆分支提供喜剧与叶晓的轻吐槽。
- **关键状态**：`locker_overpacked` 决定走哪条分支；包是否塞得下是客观结果，不是作者数值。
- **不能破坏**：
  - 交互 UI / 物品文案 / 判定逻辑不写在本剧本。
  - 叶晓在此**不塞大回忆**；"物理上好像不太允许我怀旧"是限量的自嘲，不要扩成反复互怼。
  - 文本承认"玩家实际做过什么"（塞爆过才有吐槽），从客观状态长出来。

# S06｜志愿说明

**地点 / 时间**：上午教室；老师讲志愿填报
**角色**：海象、叶晓、老师、同学

**正文**

【画面】场景切换：上午教室

【旁白】回教室，老师已经在前面讲了。
【旁白】包放回桌边。
【旁白】坐下。

【老师】专业调剂自己一定看清楚。别到时候跑来问我，"老师我怎么被调剂了"。你自己勾的服从，我有什么办法。

【旁白】下面有人笑。
【旁白】我拿出手机。
【旁白】早上的升学意向接龙还在群里。
【旁白】点开。
【旁白】已经一长串。
【旁白】但中间也空着不少名字。

【旁白】张XX：省内，计算机相关
【旁白】李XX：外地，临床
【旁白】王XX：本地，专业未定
【旁白】……

【旁白】我往下翻。
【旁白】还没我。
【旁白】再往后翻。
【旁白】还有几个也没接。

【旁白】叶晓扫了一眼。
【叶晓】你还没填？
【海象】没。
【叶晓】你不是早就看过很多遍了吗？
【海象】看过和填上去是两回事。

【旁白】前面老师还在讲。
【老师】还有，去年分数线只能参考。看位次。看位次。看位次。我今天说第三遍了。

【旁白】旁边有人凑过来一点。
【同学】你准备去哪？
【海象】还在看。
【同学】你不是都看过一轮了吗？
【海象】看过和决定是两回事。
【同学】也是。

【旁白】他哦了一声，转回去。
【旁白】我点进输入框。
【旁白】打：暂定外地，专业未定
【旁白】看一会儿。
【旁白】发出去。
【旁白】我盯着那行字看了一会儿。
【旁白】锁屏。
【旁白】下面又接了两条。
【旁白】我的名字很快被顶上去了。

（→ 接 S07）

**设计备注**
- **本场作用**：老师讲调剂（外部压力）+ 海象在群里发出"暂定外地，专业未定"。
- **关键状态**：志愿**已发出但仍是"暂定"**——问题没解决，只是交了差。
- **不能破坏**：
  - 发出后的"我盯着那行字看了一会儿 / 锁屏"心理停顿必须保留，这是志愿的"轻回响"，不是"解决"。
  - **不要写**"我终于决定了 / 未来会怎样 / 选择人生"一类升华。
  - 不新增志愿冲突。

# S07｜去吃饭

**地点 / 时间**：去食堂路上；中午
**角色**：海象、朋友

**正文**

【画面】场景切换：去食堂路上

【旁白】讲完以后，教室又散开了。
【旁白】我跟朋友去饭堂。
【旁白】路上正好碰到低年级的人往这边走。
【旁白】前面有个人手里还拿着手机。
【旁白】我看了一眼。

【海象】他怎么敢这么拿。

【旁白】老师从旁边一拐过来。
【旁白】那个人手机一下塞回裤兜。
【旁白】动作熟得不行。
【旁白】我刚想笑。
【旁白】才发现自己手机也在手上。
【旁白】手下意识往口袋那边动了一下。
【旁白】又停住。
【旁白】……
【旁白】不用收了。
【旁白】手慢慢松下来。

【旁白】旁边朋友也看见了。
【朋友】你手机拿出来一天了。
【旁白】我低头看了一眼。
【旁白】屏幕不知道什么时候已经黑了。
【海象】忘了。

**设计备注**

- **不能破坏**："手下意识往口袋动又停住"的停顿；不总结"毕业后没人管手机"。

# S08｜午饭

**地点 / 时间**：食堂；午间
**角色**：海象、朋友A、朋友B

**正文**

【画面】场景切换：食堂

【朋友B】大学那个我想几点关就几点关。
【朋友A】那你买笔记本还是台式？
【朋友B】就烦这个。

## 全局原则（落到本剧本的约束）
