## 1. Narrative role

Demo 是正式版主线的“夹心外框”，不是一篇独立完成成长的毕业短篇。

毕业日现在时 → 收拾留下的东西 → 空教室进入回忆 → 正式版：完整高中主线 → 回到毕业日 → 最后一张教室照片 / 对话 / 自拍。

Demo 在回忆入口处只用极短蒙太奇代替完整高中主线，再回到毕业日结尾。它要让玩家看见已经有历史的海象与叶晓，并产生问题：三年里发生了什么，才让他们成为现在这样？

## 2. Non-negotiable constraints

- 海象开场就知道自己毕业、高考结束、成绩公布；不能靠教室变空才“发现毕业”。
- 毕业日的情绪是已知事实逐步落到具体动作里，不是信息揭示。
- 摄影是海象看世界的习惯，不是摄影社身份、职业标签或独立模拟器。
- 叶晓与海象只呈现熟悉、默契、互损和对习惯的了解；不得锁死为恋人、前任或任何单一关系状态。
- 自拍不是女主教会主角“爱自己”的按钮，也不单独完成成长；它的意义由正式版完整主线赋予。
- Demo 只记录客观事件，不制作成熟度、自我可见性或关系类型数值条。
- 柜子与桌子必须是两种体验：柜子多物品、多取舍；桌子少物品、慢节奏、重演出。

## 3. Emotional line

返校办事 → 返校后的小得意 → 典礼一下结束 → 柜子里怎么有这么多垃圾 → 志愿：接下来去哪 → 大家仍和平时一样 → 下午的人怎么少得这么快 → 这个位置不用再坐了 → 两次空教室并不一样 → 回忆缺口 → 给高中收尾 → 最后也把主角留进画面。

## 5. Beat details

### S01｜上学路

- 海象家离学校近，不做“家到学校”的长外部上学路；开场为黑屏 + 班主任在班级群“再次提醒”升学意向统计（暂定即可）。
- 可见“上学路”主要是校门后的学校内部道路（校门→校内小路→教学楼→走廊→教室），不是校外长途。
- 检查随身：资料、相机、手机……都在；相机是他自然会带的东西。
- 不再使用“第一次找不到教室 / 提前半小时 / 后来踩铃”作为开场回忆。

### S02–S03｜走廊与第一次进教室

- 走廊柜门打开、资料和垃圾袋散落、同学翻出奇怪旧物，海象看到自己的柜子很满，但先进教室放下东西。
- 教室反而热闹：随便坐、各聊各的、光明正大玩手机；海象与一位非叶晓同学有无声熟人交流（抬下巴点头），自然进入氛围。
- 手机规则已失效但身体习惯还在：摸到手机顿一下、看讲台、反应过来没人管、放心搁桌上、小得意“……爽”。
- 叶晓自然出现。她与海象的对话仅需显出“知道对方平时会怎么回应”。
- S03 不再插入刚入学时空教室照片（该照片移至 S05 柜中 photo_pack 首次检视，S13 仍与之呼应）。

### S04｜毕业典礼

- 毕业典礼本身不做完整流程流水账。讲话作为持续背景，海象听了一阵后自然走神到志愿、学校、专业与城市。
- 中途朋友提醒“到你们了”，海象才回神跟着上台；回座后注意力又回到志愿。
- 海象刚拿出手机准备继续看学校，前排已经开始起身，才发现典礼结束。
- 核心仍是“重要的最后一次结束得比预想快”，但不再由旁白总结意义。

### S05｜柜子整理：核心交互

- 高亮可交互物品；点击进入物品图片、简短描述／小情节、去向选择。
- 物品应混合：真垃圾、当年重要如今普通的东西、朋友或叶晓相关的普通物件、后来才可能有意义的碎片。不要做成纪念品博物馆。
- 可保留物超过可带走空间；不显示生硬容量数字。以包塞不下、需要“腾个位置”呈现。
- 二次舍弃必须有新文本：第一次“反正不占地方”，第二次变成“还是得腾给别的东西”。
- 有些物品的去向不是扔掉，例如还给叶晓；系统仍只记录物品去向。
- 柜子中翻出 `photo_pack`（一袋照片）：第一张为刚入学时的空教室（黑板干净、桌椅整齐、构图微歪），照片袋不占容量、自动收好、无保留/舍弃选择；S13 回扣该照片。

### S06–S08｜志愿、低年级与午饭

- 升学意向接龙贯穿 S01→S06→S08：S01 班主任“再次提醒”未填；S06 老师讲志愿时海象重新打开同一接龙，最终提交“暂定外地，专业未定”；S08 朋友主动翻群接龙、拿海象的“暂定”开玩笑，并以“谁先录谁群里说一声”收尾。
- 志愿说明以老师声音为背景，让海象的注意力落在分数、专业、去处、家人意见和朋友未来；不做现实填报教学。
- 午饭路遇低年级放学。低年级仍在上课、赶作业、藏手机；海象故意将手机拿在手上，享受刚脱离规则的幼稚爽感。
- 午饭先让朋友说垃圾话、聊电脑／日常，再从接龙自然谈到各自可能去哪，不做“说起来你们志愿填得怎么样了”的编剧转场；默认寒假还会聚，但不做告别总结。没有人把它当成永别。

### S09–S12｜下午教室、叶晓与桌子

- 高考前后，教材、练习册、成摞资料、大件文具和个人物品已经陆续搬回家；下午教室留下的是逐渐减少的座位、袋子和细碎残留。
- 叶晓同样有一大堆东西；她不是陪主角成长的工具人。双方各自整理，以无需解释的熟人动作表现亲近。
- S11 不再检视普通大书，而只检视桌上的贴纸与桌洞里几张不规则小纸片；它们是之前几轮整理懒得专门处理的日常残留，不承担重要剧情解释。
- 桌面存在新旧不一的贴纸。贴纸来源、学长、海象为何长期使用这张桌子、换座时是否搬过整张桌子，留给正式版主线；Demo 不提前解释。
- 玩家看过两件物品后，真正清理小纸片、纸屑和翘起的贴纸留在 Timeline；保留“书包习惯性挂回桌边 → 停顿 → 取下背好”的身体动作。
- S12 的离场节奏暂按当前稿保留，后续如需重做另开一轮。

### S13–S17｜回忆入口与句号

- S13 保持当前无对白照片回闪：叶晓收好最后一个袋子，海象抬头，短暂停顿后显示 `first_day_classroom`，再直接进入 S14。
- 正式版在此进入完整高中主线。Demo 仅用开学、雨、操场、笑声、考卷、午睡、快门、夕阳等碎片蒙太奇暗示缺失的故事；S14 当前灰盒结构不在本轮重做。
- S15 只写眼前动作：海象挪几步、停下、举起相机并拍下最后一张教室照片；不重复叶晓拉最后一个袋子的拉链，也不解释拍摄位置或照片意义。
- S16 保留现有日常对白，不扩写关系解释。
- S17 固定发生自拍，但不由叶晓诊断海象“很少拍自己”来解释意义；自拍从“我有什么好拍的 / 那我呢 / 一起拍”等眼前普通互动自然发生。第一次把海象留进画面属于作品设计层，不直接写成角色主题台词。

## 6. Candidate dialogue pool

这些是候选声线，不是最终 Script；正式文本需由最终主线中的海象与叶晓状态重写。

- 典礼： “……没了？”
- 柜子容量： “物理上好像不太允许我怀旧。”
- 手机： “你手机拿出来一天了。” / “我回消息。” / “你屏幕都黑半天了。” / “省电。”
- 熟悉感： “你终于来了。” / “我又没说你迟到。” / “因为你每次都这么回。”
- 无用物： “这个也带？” / “嗯。” / “有什么用？” / “没用。” / “那你带它干嘛？” / “不知道。”
- 最后照片： “这样就算收完了。”

## 7. Implementation boundary

### Required for the demo

- ADV 对话基础；
- 场景热点交互；
- 物品检视 UI；
- 柜子保留／舍弃与有限携带空间；
- 已保留物品的二次舍弃；
- 照片显示／检视；
- 轻量回忆闪回与场景状态变化。

### State to record

    locker_items_kept
    locker_items_discarded_initially
    locker_items_discarded_later
    locker_items_returned
    optional_interactions_seen
    photos_seen
    minor_dialogue_choices

不得为了 Demo 提前编码人物成熟度、关系标签或整部作品的结局状态。
不得制作“怀旧度”“放下过去度”“叶晓好感度”等任何数值条；Demo 只记录客观事件与物品去向。

### Transient presentation state（不长期保存）

    locker_overpacked

仅用于 S05 结束时的即时分支（包塞不下 → 触发二次取舍演出），是演出状态而非人物属性，
不写入长期状态、不跨 Scene 保存、不进入存档。
