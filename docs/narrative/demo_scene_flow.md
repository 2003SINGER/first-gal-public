## 1. Narrative role

Demo 是正式版主线的“夹心外框”，不是一篇独立完成成长的毕业短篇。

毕业日现在时 → 收拾留下的东西 → 空教室进入回忆 → 正式版：完整高中主线 → 回到毕业日 → 最后一张教室照片 / 对话 / 自拍。

Demo 在回忆入口处只用极短蒙太奇代替完整高中主线，再回到毕业日结尾。它要让玩家看见已经有历史的海象与叶晓，并产生问题：三年里发生了什么，才让他们成为现在这样？

## 2. Non-negotiable constraints

- 海象开场就知道自己毕业、高考结束、成绩公布；不能靠教室变空才“发现毕业”。
- 毕业日的情绪是已知事实逐步落到具体动作里，不是信息揭示。
- 摄影是海象看世界的习惯，不是摄影社身份、职业标签或独立模拟器。
- 叶晓与海象只呈现熟悉、默契、互损和对习惯的了解；不得锁死为恋人、前任或任何单一关系状态。
- 自拍不是女主教会主角“爱自己”的按钮，也不单独完成成长；它的意义由正式版完整主线赋予。
- Demo 只记录客观事件，不制作成熟度、自我可见性或关系类型数值条。
- 柜子与桌子必须是两种体验：柜子多物品、多取舍；桌子少物品、慢节奏、重演出。

## 3. Emotional line

返校办事 → 返校后的小得意 → 典礼一下结束 → 柜子里怎么有这么多垃圾 → 志愿：接下来去哪 → 大家仍和平时一样 → 下午的人怎么少得这么快 → 这个位置不用再坐了 → 两次空教室并不一样 → 回忆缺口 → 给高中收尾 → 最后也把主角留进画面。

## 5. Beat details

### S01｜上学路

- 海象检查资料、相机、手机等返校物品；语气应是“回来办完最后几件事”，不是抒情开场。
- 路线是日常上学路，因此可出现极短的第一次入学印象：怕找不到教室、提前到、后来反而常踩铃进门。
- 这些只能是 Memory Glimpse：一句内心、短环境音变化或旧照片闪现；不得在此进入完整回忆。

### S02–S03｜走廊与第一次进教室

- 走廊柜门打开、资料和垃圾袋散落、同学翻出奇怪旧物。海象看到自己的柜子很满，但先进入教室。
- 教室反而热闹：随便坐、聊分数和志愿、拍照、光明正大玩手机。
- 插入一张刚入学时随手拍下的空教室照片：干净黑板、整齐桌椅、生涩构图。它与之后的最后一张照片形成首尾，不必当场解释。
- 叶晓自然出现。她与海象的对话仅需显出“知道对方平时会怎么回应”。

### S04｜毕业典礼

- 用快速镜头压缩讲话、掌声、发证、合影、起立与散场。
- 核心不是仪式规模，而是海象对其过快结束的短暂诧异；重大事件并不自动获得电影感。

### S05｜柜子整理：核心交互

- 高亮可交互物品；点击进入物品图片、简短描述／小情节、去向选择。
- 物品应混合：真垃圾、当年重要如今普通的东西、朋友或叶晓相关的普通物件、后来才可能有意义的碎片。不要做成纪念品博物馆。
- 可保留物超过可带走空间；不显示生硬容量数字。以包塞不下、需要“腾个位置”呈现。
- 二次舍弃必须有新文本：第一次“反正不占地方”，第二次变成“还是得腾给别的东西”。
- 有些物品的去向不是扔掉，例如还给叶晓；系统仍只记录物品去向。

### S06–S08｜志愿、低年级与午饭

- 志愿说明以老师声音为背景，让海象的注意力落在分数、专业、去处、家人意见和朋友未来；不做现实填报教学。
- 午饭路遇低年级放学。低年级仍在上课、赶作业、藏手机；海象故意将手机拿在手上，享受刚脱离规则的幼稚爽感。
- 午饭先让朋友说垃圾话、聊电脑／游戏／日常，再自然过渡到城市、专业、暑假和“以后回来再约”。没有人把它当成永别。

### S09–S12｜下午教室、叶晓与桌子

- 下午教室的座位、包和说话声都明显减少。朋友以“走了，群里说”之类的日常方式离场。
- 叶晓同样有一大堆东西；她不是陪主角成长的工具人。双方各自整理，以无需解释的熟人动作表现亲近。
- 桌子整理不复用柜子系统：取出最后物品、擦桌面、看到痕迹、清空桌洞。关键是座位从“我的位置”变回普通桌子。
- 可保留无对白动作：海象收完后习惯性把书包挂回桌边，再停顿并取下背好。
- 背景中的道别、门开合、走廊／球场／风声逐步取代人声；玩家应亲眼看见教室变安静。

### S13–S17｜回忆入口与句号

- S13 将早上的初始空教室照片与眼前空教室并置：第一次是什么都还没发生；现在是什么都发生过了。
- 正式版在此进入完整高中主线。Demo 仅用开学、雨、操场、笑声、考卷、午睡、快门、夕阳等碎片蒙太奇暗示缺失的故事。
- 回到现在后，海象在接近第一次拍照的位置拍下最后一张教室照片；这是固定句号动作，不做成成长选择。
- 叶晓听见海象无意的感慨后看见照片，指出他最后仍把自己留在镜头外。
- 自拍以日常、略不完美的互动完成；不得用永远、承诺或关系名称锁死结局。

## 6. Candidate dialogue pool

这些是候选声线，不是最终 Script；正式文本需由最终主线中的海象与叶晓状态重写。

- 典礼： “……没了？” / “原来最后一次也不会自动变慢。”
- 柜子容量： “物理上好像不太允许我怀旧。”
- 手机： “你手机拿出来一天了。” / “我回消息。” / “你屏幕都黑半天了。” / “省电。”
- 熟悉感： “你终于来了。” / “我又没说你迟到。” / “因为你每次都这么回。”
- 无用物： “这个也带？” / “嗯。” / “有什么用？” / “没用。” / “那你带它干嘛？” / “不知道。”
- 空教室： “原来空教室看起来都差不多。” / “明明一点也不一样。”
- 最后照片： “这样就算收完了。”

## 7. Implementation boundary

### Required for the demo

- ADV 对话基础；
- 场景热点交互；
- 物品检视 UI；
- 柜子保留／舍弃与有限携带空间；
- 已保留物品的二次舍弃；
- 照片显示／检视；
- 轻量回忆闪回与场景状态变化。

### State to record

    locker_items_kept
    locker_items_discarded_initially
    locker_items_discarded_later
    locker_items_returned
    optional_interactions_seen
    photos_seen
    minor_dialogue_choices

不得为了 Demo 提前编码人物成熟度、关系标签或整部作品的结局状态。
不得制作“怀旧度”“放下过去度”“叶晓好感度”等任何数值条；Demo 只记录客观事件与物品去向。

### Transient presentation state（不长期保存）

    locker_overpacked

仅用于 S05 结束时的即时分支（包塞不下 → 触发二次取舍演出），是演出状态而非人物属性，
不写入长期状态、不跨 Scene 保存、不进入存档。
